03. How it works

How a project runs, start to finish

01

Agree what you get

We start from the finished output, not the technology. You tell us what you need and where it goes. We agree the format, the schedule and how each one is checked.

You get: an agreed list of outputs
02

We run the workflow

Alvento owns and operates the automation, so there is nothing for your team to build, host or maintain.

You get: finished outputs, on schedule
03

Review and deliver

A person checks each output before it reaches you. Your feedback shapes the next round.

You get: reviewed work you can use
You buy the outputs. Alvento runs the automation. The engagement is for the agreed outputs. The automation is not transferred as part of the service.
