Website audit: UK membership body, worked example

Site profile: WordPress, a members' area, an annual congress/event page, roughly 15,000 members, typical of a UK professional or specialty body. Six-section executive summary, prioritised risk register, three fixed-scope remediation tiers. This is the format every Alvento website audit is delivered in.

01. Overall assessment

Site health score

58/100
A membership-facing site with strong content but structural gaps that create real risk: an inaccessible event-registration flow, missing statutory accessibility statement, and SEO fundamentals that leave the organisation invisible for the searches its own members run most often.

03. Detailed findings

Six areas assessed

01

SEO

42/100
  • No meta descriptions on 60% of pages
  • Title tags don't follow a consistent, search-relevant pattern
  • No sitemap submitted to Google Search Console
02

Accessibility

31/100
  • No accessibility statement (Accessibility Regs 2018, reg. 7)
  • Registration form fails SC 2.4.7 (Focus Visible), no visible keyboard focus states
  • Primary CTA fails SC 1.4.3 (Contrast Minimum), 3.1:1 against the 4.5:1 AA threshold
03

Performance

55/100
  • Unoptimised hero images add 2.1s to mobile load
  • No caching headers on static assets
  • Render-blocking third-party scripts in the head
04

Security

70/100
  • TLS configuration current, no weak protocols
  • Missing Content-Security-Policy header
  • Admin login has no rate limiting visible
05

UX

61/100
  • Committee/governance info buried three clicks deep
  • No clear path from homepage to member renewal
  • Mobile navigation menu overlaps page content
06

Event/congress page pass

48/100
  • No schema.org Event markup on the annual congress page
  • Registration form fails WCAG 2.2 SC 2.1.1 (Keyboard) again on this page's own form instance
  • No confirmation email trigger visible in the flow
04. Recommended priorities

7-day / 30-day / 90-day

7 days

  • Publish a PSBAR-compliant accessibility statement
  • Fix colour contrast on primary CTAs
  • Add Content-Security-Policy header

30 days

  • Rebuild the event-registration form for keyboard/screen-reader access
  • Compress and lazy-load hero imagery site-wide
  • Add meta descriptions and consistent title-tag pattern

90 days

  • Add schema.org Event markup to the annual congress page
  • Restructure navigation so governance/committee info is one click from the homepage
  • Submit sitemap and monitor search visibility monthly
