Release and pricing plan

Free now. A one-time unlock later.

The current 0.4.2 build has no billing and no item cap. A later release will introduce a 30-item free allowance across photos, files and notes, and a one-time purchase to add more.

Existing items, editing, export, backup and restore will remain free, including access to a vault already above 30 items. No subscription is planned for that release. Final purchase pricing will be shown before you buy.

Public release timing has not been announced. This page will link to the public Google Play listing when it is available.

Moving from an earlier test build?

If you used the earlier sideloaded app with package name uk.alvento.cellar, the current uk.alvento.nullkey is a separate app. Installing it does not transfer your vault.

  1. Create and verify an encrypted backup in the old app.
  2. Keep the passphrase or recovery key for that backup separately.
  3. Restore into an empty NullKey vault and check the contents.
  4. Only then consider removing the old app. Keep your independent backup.

Do not uninstall or clear the old app before verifying the restored copy.
