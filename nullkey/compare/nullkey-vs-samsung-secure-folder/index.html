NullKey vs Secure Folder (Samsung Galaxy)

NullKey is an Android app that keeps private notes, documents and photos in an encrypted vault on the phone, with no account. Secure Folder is Samsung's feature for Galaxy devices, set up from Settings, which holds photos, videos, files, apps and data.

The honest case for Secure Folder

Secure Folder is the better fit for readers who already use a Samsung Galaxy phone and want the feature set up from Settings on that device. Its UK support page says some older phone models may no longer support it, so check that first. It also lists apps among the things it holds, while NullKey stores notes, documents, photos and other files.

Readers who want an auto sync switch, a name or icon they can change, or a reset that runs through an account may find those features useful. Its US support page describes an 'Auto sync Secure Folder data' switch under Manage accounts and says the name and icon can be changed. Its help pages describe a reset using a Samsung account.

Encryption and unlock options

Samsung says its Knox security platform encrypts all data stored in the Secure Folder. NullKey's published wording names AES-256-GCM for stored contents, gives each item its own random key, and protects the vault's keys with a key that Argon2id derives from your passphrase.

Samsung's UK page says a passcode or biometric lock can be added, and its US page lists PIN, password or pattern locks, with fingerprint unlock on supported devices. NullKey offers an optional strong-biometric unlock, and phone screen-lock and in-app pattern unlock on supported devices. Its pattern is a convenience with weaker protection than the passphrase.

Recovery and accounts

Setup for Secure Folder needs a Samsung Account, which you sign in to or create. Its UK support page describes a reset using that account, and its US page says the reset needs Reset with Samsung account to have been turned on. NullKey has no account and no account reset.

NullKey's recovery key is one you save yourself, and it opens existing encrypted data. It is not a backup, so keep a separate copy of anything you cannot replace.

Backup, contents and appearance

Samsung's US support page describes an 'Auto sync Secure Folder data' switch under Manage accounts. The same page says backing up Secure Folder data is no longer supported, but data from previous backups can still be restored and the Secure Folder can be transferred to a new device using Smart Switch. NullKey has no sync, and its current app declares no internet permission. You can save an encrypted backup wherever you choose with Android's file picker.

Its UK support page says Secure Folder stores photos, videos, files, apps and data. NullKey stores private notes, documents and photos. Secure Folder's name and icon can be changed, and its icon can be hidden from the Home and Apps screens. NullKey does not disguise its app or show a decoy.

Bottom line

Choose Secure Folder if you use a Samsung Galaxy phone and want it set up from Settings, with a reset through your Samsung Account if you turn that option on, and the auto sync switch. Choose NullKey if you want an app that needs no account, a recovery key you save yourself, and an encrypted backup saved wherever you choose, on Android 12L or later.

Frequently asked questions

Does Secure Folder need a Samsung Account?

Its UK support page says setup needs a Samsung Account, which you sign in to or create. NullKey has no account, so there is nothing to sign in to.

Is Secure Folder encrypted?

Samsung says its Knox security platform encrypts all data stored in the Secure Folder. NullKey encrypts its contents with AES-256-GCM, gives each item its own random key, and protects the vault's keys with a key that Argon2id derives from your passphrase.

Can Secure Folder be hidden or renamed?

Its US support page says the name and icon can be changed, and its UK page says the icon can be hidden from the Home and Apps screens. NullKey does not disguise its app or show a decoy.
